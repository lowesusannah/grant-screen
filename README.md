# grant-screen

A tiny demo project to show use of ci/cd using GitHub Actions. This app will identify grant proposals for further due diligence based on a financial threshold.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Usage

```bash
npm start
```

## Features

- Grant submission and tracking
- Screening and evaluation tools
- Report generation
